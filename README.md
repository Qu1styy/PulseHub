# Lab3

Учебный проект на Django, представляющий собой сайт с опросами, профилями пользователей и микроблогом. Проект создан для закрепления основных навыков работы с Django: моделями, представлениями, шаблонами, формами, авторизацией, статическими и медиа-файлами.

## Что реализовано

### 1. Опросы

- создание вопросов с описанием и изображением;
- добавление вариантов ответа;
- регистрация голосов пользователей;
- проверка, что пользователь не голосовал повторно;
- ограничение по срокам активности вопроса;
- отображение результатов голосования в процентах.

### 2. Профиль пользователя

- регистрация и вход в систему;
- редактирование профиля;
- загрузка аватара;
- поле "О себе";
- удаление профиля.

### 3. Микроблог

- создание постов;
- просмотр ленты постов;
- лайки к постам;
- комментарии к постам;
- редактирование и удаление собственных постов и комментариев;
- постраничная навигация.

## Основные модели

### UserProfile

- связь один-к-одному с пользователем Django;
- аватар;
- информация о пользователе.

### Question

- текст вопроса;
- краткое и подробное описание;
- дата публикации;
- срок истечения;
- автор;
- изображение.

### Choice

- вариант ответа;
- количество голосов.

### Vote

- связь между пользователем, вопросом и выбранным вариантом;
- запрет повторных голосов.

### MicroblogPost

- текст поста;
- автор;
- дата создания;
- количество лайков.

### PostLike

- лайк пользователя к посту.

### PostComment

- комментарий к посту;
- автор;
- дата создания.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Qu1styy/lab3.git
cd lab3
```

### 2. Создание виртуального окружения

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### Linux/macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install django pillow
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Запуск проекта

```bash
python manage.py runserver
```

После запуска проект будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Основные маршруты

- `/polls/` — главная страница опросов;
- `/polls/register/` — регистрация пользователя;
- `/polls/login/` — вход в систему;
- `/polls/profile/` — профиль пользователя;
- `/polls/create-question/` — создание вопроса;
- `/polls/<id>/` — страница вопроса;
- `/polls/<id>/results/` — результаты голосования;
- `/polls/microblog/` — лента постов;
- `/admin/` — административная панель Django.

## Принципы проекта

Этот проект направлен на изучение и практику следующих тем Django:

- создание и настройка проекта;
- работа с моделями данных;
- создание форм и валидация данных;
- отображение данных через шаблоны;
- использование `ListView` и `DetailView`;
- работа с пользователями и авторизацией;
- хранение и загрузка изображений;
- связь моделей через `ForeignKey` и `OneToOneField`;
- реализация логики голосования и рейтинга;
- создание социальной части приложения с лайками и комментариями.

## Ограничения

Это учебный проект, поэтому:

- данные хранятся в SQLite;
- нет полноценной production-сборки;
- отсутствует продвинутая система безопасности и деплоя;
- функциональность ориентирована на обучение, а не на продакшн-использование.
